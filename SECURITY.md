# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| v0.2.x | Yes |
| v0.1.x | Security fixes only |
| < v0.1.0 | No |

## Reporting a Vulnerability

The Kryvora Network core engineering team takes the security of our distributed infrastructure seriously.

If you identify a security defect, memory corruption issue, or protocol exploit:

1. Do NOT file a public GitHub issue.
2. Email full technical reproduction details to `security@kryvora.network`.
3. Include component version, target operating system, and proof of concept payload.

Our core security team will acknowledge receipt within 48 hours and coordinate remediation before public disclosure.
